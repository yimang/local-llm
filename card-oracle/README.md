# Card Oracle

Trading-card projects live here as independent project directories. Each project
owns its data, configuration, scripts, evaluation, and documentation. Use the
repository's shared uv environment; do not create a second dependency lockfile.

- [Query segmentation](query-segmentation/README.md): synthetic card-search data
  and a planned ModernBERT token-classification baseline.

Keep future projects alongside query-segmentation. Introduce shared libraries or
catalogs only when multiple projects actually need them.
